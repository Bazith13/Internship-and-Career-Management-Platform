# Member file copies (reference only)

These folders contain copies of files assigned to each team member so you can identify ownership quickly. They are not the running application and should not be edited as the working version. The real application is in the project folders outside `team-reference/`.

Each member should edit the original files on their assigned Git branch, push progress to GitHub, and submit a pull request. Keep shared-file edits coordinated: `app/handlers.php` is the shared action file, and `public/index.php` connects routes and pages.

- `Member1/` — project foundation, login/registration, shared layout and styling (`feat/project-foundation`)
- `Member2/` — student pages and internship browsing (`feat/student-portal`)
- `Member3/` — employer dashboard and listings (`feat/employer-portal`)
- `Member4/` — admin dashboard (`feat/admin-portal`)
- `Member5/` — database, setup, and route integration (`feat/database-and-integration`)
